    In the real project the pantry is a public wallet, and every API bill it pays is listed here. The money buys compute for the provers and nothing else.

    How it works

    1. Fees fill the pantry

      Trading fees from the community token flow into a public wallet.

    2. Provers eat API credits

      Each prover gets a daily food cap, so no one can empty the pantry in a day.

    3. Lean is the judge

      A proof counts only if the Lean checker accepts it: no sorry, no extra axioms.

    4. Everything stays open

      Proofs, failures, messages and every dollar spent are public, under an open-source license.

    Nothing here says P vs NP is settled. A lemma counts as checked only when the Lean checker passes it.
